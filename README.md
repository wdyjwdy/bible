# Bible

A simple Bible web app.

## Features

- [x] Optimized for mobile
- [x] Paragraph or list layout
- [x] Dark mode
- [ ] Add to favorites
- [ ] Search function
- [ ] Highlight names of people and places
- [ ] Compare translations layout
- [ ] Adjustable font size

## Translations

- CUS: 简体中文和合本
- KJV: King James Version
